📨 Cài Đặt Telegram Bot

💡 ESP32 là nguồn gửi Telegram chính. Web chỉ lưu cấu hình và gửi tin test để tránh trùng cảnh báo.

📖 Hướng dẫn

1
Mở Telegram → Tìm @BotFather → Gửi /newbot → Copy token
2
Tìm @userinfobot → Nhắn bất kỳ → Copy ID
3
Dán token và ID vào ô trái → Nhấn Gửi Test
